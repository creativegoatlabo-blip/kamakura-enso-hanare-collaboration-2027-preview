# 鎌倉彫金工房 × enso hanare 別案（2フレーム）

Anthropic の `frontend-design` を用いた別案。既存の Hallmark 案とは別ディレクトリに置く。

## デザイン方針

- 色：深い緑 `#18312d`、墨緑 `#11231f`、銀鼠 `#e0e5dc`、白緑 `#f2f5ee`、文字色 `#21332d`。料理写真の橙と指輪の金属色を、背景の装飾色で繰り返さない。
- 文字：`Zen Kaku Gothic New` を日本語の本文と見出しに、`Jost` を日付・時刻・金額に使用。
- 構成：第1フレームは料理写真を右側いっぱいに置き、指輪の写真を境界に重ねる。第2フレームは制作・徒歩移動・ディナーを一本の時系列で見せる。
- 写真の重なりだけを主役にし、飾りの円やカードは増やさない。暗い料理写真と明るい指輪写真の差を、体験の移り変わりとして使う。

## 内容の出典・注意

- 日付・曜日・金額・時刻・予約方法・料理の方向性は、2026年9月24日に更新された Notion「タイアップ：OSAJI enso」を基準にした。
- 店名は[enso hanare 公式サイト](https://www.enso-osaji.net/)の表記を採用した。
- 写真は現在のプレビュー用に両ブランドのInstagram公開投稿を再利用したもの。ensoから支給される正式素材を受け取ったら差し替える。ディナー写真は限定コースの内容を示すものではない。
- GoogleフォームURLが未提供のため、申し込みリンクは未設置。フォーム送信後も、両店舗の確認と鎌倉彫金工房からの連絡をもって予約確定となる。
- `noindex` を設定したプレビュー用ページ。公式サイトへの反映前に写真の利用条件・コースの詳細・予約規定を確認する。
