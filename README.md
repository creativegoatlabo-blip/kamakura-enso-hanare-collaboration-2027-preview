## 写真・動画の出典

- 鎌倉彫金工房：[@kamakura_chokin の動画「モーニングルーティン」](https://www.instagram.com/p/DdD5RoIRUm0/)をInstagramの公式埋め込みでFVに配置。背景の表紙画像も同じ投稿から取得。

写真と表紙画像は両ブランドのInstagram公開投稿から2026年9月24日に取得し、このプレビューに配置しました。enso の写真はWeb表示用に縮小しています。動画の再生にはInstagramへの接続が必要です。本番サイトへの転用時には写真・動画の使用条件とクレジット表記を両ブランドで確認してください。enso の写真は限定ディナーの実際のコース内容を示すものではありません。
